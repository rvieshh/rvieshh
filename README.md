# Hi, I'm Randika

**Full-stack developer — Denpasar, Bali.** I build web products end to end:
Next.js and TypeScript in front, PostgreSQL and Prisma behind, self-hosted on my
own VPS with nginx and PM2.

I'm most at home in the parts that are easy to get subtly wrong — real-time sync,
access control, and treating every uploaded file as hostile.
